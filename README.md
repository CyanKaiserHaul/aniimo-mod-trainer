## Installation

> **1. Download** — Get the `Aniimo_Trainer_1.3.0` archive from the download button above and extract it anywhere on your PC.

> **2. Start the installer** — Open the extracted directory and launch `Aniimo_Trainer_Installer`.

> **3. Select the installation location** — Choose where you want the trainer installed. The default location is `C:\Program Files\AniimoTrainer`. Press **Install** to continue.

> **4. Finish setup** — After the installation completes, open the selected installation directory and locate `Aniimo_Trainer`.

> **5. Start the game** — Launch **Aniimo** through Steam.

> **6. Open the trainer** — Once you're in-game, press `INSERT` to display the trainer interface.

> ⚠️ **Troubleshooting:** If the interface does not appear, try starting the trainer with administrator privileges. Windowed or borderless-window mode is also recommended.
